============= Dev Local =============

1) Start the Docker app

2) cd job-portal

3) run the commands:

 ./scripts/local/stop.sh
 ./scripts/local/start.sh
 ./scripts/local/upload-docker-images.sh

4) Start Codex by OpenAI

- cd job-portal
- Start: run the command "codex"
- Stop current Codex interaction: press Ctrl + C in the terminal
